# Software Project Management: end-semester study guide

BE IT Semester VII, SPPU 2019 pattern, subject 414442. These original study guides and paper-specific answers cover Units 3–6. Answers include both sides of each OR; headings are paraphrased, examples are illustrative, and model answers are expanded toward nine marks even where the actual paper assigns fewer or more marks.

## Exam technique

For a nine-mark answer, define the concept, explain the main steps or components, draw and label a suitable diagram, provide a relevant example or calculation, and mention advantages, limitations or a short conclusion as appropriate. For calculations state assumptions and show formulas and units. Adapt the level of detail to the marks and time available.
